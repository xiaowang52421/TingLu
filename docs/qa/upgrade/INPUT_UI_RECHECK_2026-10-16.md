# 输入、菜单与设置源码复核（2026-10-16）

状态：PARTIAL；完成只读源码/测试审查。未启动 Unity、未构建、未进行真实鼠标/触屏/窗口操作。

## 确定观察

- **窄窗口菜单会超出视口。** [AccessibleMenuPanel.cs](../../../Assets/TingLu/UI/AccessibleMenuPanel.cs) 将面板宽度限制为至少 220 px，并固定从 x=24 px 开始。宽度低于 268 px 时宽度下限生效；面板右缘固定在 x=244 px，所以只有视口宽度低于 244 px 时才会实际越界（例如宽度 200 px 时右缘为 x=244 px）。宽度在 244–267 px 时仍能放下，但右侧留白少于 24 px。视口高度小于 49 px 时，面板高度被设为 1 px，起点仍在 y=24 px，菜单基本不可见。这是布局公式可直接推出的边界问题；实际剪裁外观未截图确认。优先级低（P3），建议 11 调整为按可用尺寸布局，并在窄窗口复核。

## 接线审查

- **玩法输入与菜单动作分流：源码符合契约。** [StreetInputSampler.cs](../../../Assets/TingLu/Input/StreetInputSampler.cs) 在玩法态仅把右键按下沿作为探测；菜单态把右键/Enter/Space映射为确认，左键没有被读作菜单输入，交由 IMGUI 控件处理。Escape 暂停，G 保留目标查询；Space/Shift 不生成玩法探测或主动聆听动作。移动通过 `StreetCoordinates.ScreenMove` 归一化，转向使用相对 `Mouse.delta.x` 与配置灵敏度，不乘帧时间。
- **生命周期：源码路径存在，实机仍未证。** `SetGameplayActive` 状态变化、`Clear`、应用失焦/暂停、禁用和退出会清理并释放指针；恢复读帧会丢弃过渡帧，已按住的键/右键要先释放才能重新生效。`StreetEntry` 在菜单屏幕变化、失焦和恢复时调用相应接口。OS 锁鼠、Alt+Tab 后残留 delta、实际重复点击与恢复焦点均未实测。
- **菜单无玩法按钮：组件代码符合预期，场景实图未复核。** 新场景 `StreetCrossroads.unity` 仅绑定 `StreetEntry`；新 HUD 玩法态绘制状态与可选字幕，没有方向、聆听、敲杖、暂停或目标按钮。旧 `DemoEntry` 仍有触屏按钮代码，但它不在新场景绑定中。需要在正式 Player 中确认触屏设备连接不会由其他接线增加覆盖层。
- **操作说明：新入口文本正确。** `StreetSession.Start` 的首次开始提示是 WASD、移动鼠标转向、右键敲杖和持续听见周围声音；未要求 Shift 或空格敲杖。所搜到的 Shift 文案仅在关卡编辑器操作说明中，不是新游戏教学。
- **可达性设置：本轮可见接线。** 音量在 `StreetEntry.Update` 传入 `UnityAudioPlayback.SetMasterVolume`；字幕/显示方式/字号/调色与声纹定位强度由 HUD/RenderPlan 读取；菜单调整通过 `SaveOptions` 更新 Session 并写隔离的 Options 保存目录。耳机/扬声器选项只更新并持久化偏好值；根据总控提供的旧基线事实，这不是本轮新增阻断项。`UnityAudioPlayback.SetVoiceprintIntensity` 没有在新入口调用，不过 `StreetRenderPlan` 已按同一设置控制声纹显示强度；音频强度是否也应同步由总控按既定产品语义决定，本审查不将整项设置判为失效。
