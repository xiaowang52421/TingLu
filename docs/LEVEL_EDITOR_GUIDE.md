# 零代码关卡编辑器使用说明

本版在 Unity 内提供中文图形工作台。制作关卡只需鼠标和表单，不需要写 C# 或修改 JSON。它仍需要 Unity，不是独立安装软件。本机已检出并实际运行 Unity 2022.3.62f1c1；自动检查与鼠标操作的验收状态分别记录在文末。

## 打开编辑器

1. 用 Unity Hub 打开这个工程目录，使用 `ProjectSettings/ProjectVersion.txt` 指定的 Unity **2022.3.62f1c1**，等待包解析完成。工程可以放在其他盘或目录；保留工程的 Built-in、Input System 1.7.0 和现有包版本。
2. 顶部菜单选择 **TingLu → 关卡编辑器**。首次打开有中文帮助；之后点顶部“使用帮助”重看。
3. 初始内容是“第一步”可编辑模板。顶部显示名称、保存位置和“未保存”。编辑画布能看全图，正式试玩仍只显示游戏感知与记忆。

## 最短示例：复制第一步并试玩

1. 点 **第一步模板 → 复制关卡**。如有修改，弹窗提供保存草稿、放弃、取消。副本有独立关卡与对象标识，原首关内容保留。
2. 左侧“关卡对象”点 **电线杆**定位，或在地图点击杆。将杆拖到原位置右侧一点；需要旋转时拖动白色朝向线末端的小圆。右侧也能按米填写位置、尺寸和朝向。
3. 左侧点 **剧情提示**，再点地图。右侧写“前面是转弯，慢慢走。”，触发条件选“进入区域”。需要与门卫、鸟鸣等对象关联的对白，选择“合法感知关联对象”，选关联对象，并按需勾选“触发区跟随关联对象”。对象本身的对白始终等待合法感知。
4. 点 **保存**，建议使用保存窗口默认打开的关卡模块 `Data` 目录。这个目录随关卡模块移动，界面会显示当前位置。JSON 由界面管理，用户不用手工打开修改。允许保存尚未做完的草稿。
5. 点 **检查关卡**。错误会阻止试玩；点击问题可定位对象。警告用于辅助检查，不能证明真人纯音频一定能通关。
6. 点 **试玩**。试玩将当前工作台内容直接交给正式游戏业务，可以测试未保存的修改；不会覆盖正式玩家存档。点 Unity 顶部停止按钮结束，恢复原来的编辑场景及启动场景，回到工作台。
7. 用 **打开**重新打开保存的文件，再试玩，确认保存和重载后的内容一致。

## 地图和盲道

- 素材可点击后放置，也可从素材面板拖入地图。支持出生点、终点、电线杆、固定单车、行人、门卫、鸟鸣、碎片、检查点、剧情提示、墙/围挡和矩形地面。
- 在画布拖动物体改变位置；滚轮缩放；中键或 Alt + 左键平移；“查看整个关卡”让地图全部进入视野。坐标 +Y 朝上，1 单位为 1 米。
- “吸附网格”将移动位置吸附到 0.5 米，旋转吸附到 15 度；关闭后可以精细摆放。原模板的无伤绕杆节点不因保存而吸附变化。
- 点“连续绘制盲道”后依次点击地图添加节点，取消绘制后可拖动节点。节点与物体重合时 **Shift + 单击**优先选节点。选中节点后右栏提供“在后方插入节点”“删除节点”。
- “清空盲道重新绘制”可重画整条路径，可撤销。盲道只使用一条连续折线，宽度为 0.2–0.8 米。首版最多 5000 个运行导向段，避免超长路线卡住编辑器。
- 地面和围挡使用矩形：在右侧填写宽度、长度、朝向和中文材质。出生点朝向在地图上显示箭头。检查点需放在与障碍有身体空隙的安全位置。

## 剧情、声音和进度

- “剧情提示”可选择关卡开始、进入区域或合法感知关联对象。开始提示不能依赖前置剧情；其他提示和终点可选择先触发的剧情。
- 素材对应固定的执行动作：播放对白/提示、激活安全检查点、合法感知后收集碎片、终点结算。这里没有脚本表达式或任意可编程节点。
- 跟随关联对象的提示使用相对位置，移动关联物体会一起移动触发区；关闭跟随后使用独立位置。删除关联对象后，检查器会要求重选关联或解除绑定。
- 声音选项为当前已注册的合成占位鸟鸣、脚步、门卫、检查点、敲杖和回声。选择“无声音”不播放此项声音。碎片以及需要合法感知的无轮廓声源必须有声音，否则检查会阻止试玩并提示修复。没有正式录音、正式配音或编辑器内试听；请在试玩中测试真实设备输出。
- 行人和门卫保持动态类别，不写入永久静态记忆。选中人物后可添加行走路线，在画布点击绘制；按住 **Shift** 点击紫色路线节点后拖动，也可在右侧设置坐标、到达时间和朝向。未添加路线的人物停在布置的位置。循环路线须用末节点回到起点并保持相同朝向，检查器会拒绝会瞬移的循环。移动人物会平移其整条路线，复制人物会复制路线并生成独立标识。正式首关和可编辑模板均使用配置路线。
- 玩家移动、聆听、敲杖、勇气/专注、感知、永久记忆、碰撞、失败恢复和星级均沿用游戏业务。一个新关不必有门卫；终点前置可设“无”。相同位置的碎片会先收集，再结算终点。

## 保存、撤销与快捷键

- 保存使用临时写入、替换与 `.bak` 上次保存备份；失败会提示并保留原文件。不支持的未来版本或损坏文件不能覆盖。未完成内容能保存草稿，错误配置不能试玩。
- 复制关卡、另存到其他文件生成新的关卡/对象/节点标识，并重映射关联；移动、改名、普通保存保留标识。复制单个碎片会更新其自身关联。
- Delete 删除；Ctrl+C / Ctrl+V 复制粘贴；Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+S 保存。在文本输入中不触发这些画布快捷键，避免误删或误粘贴。
- 添加、属性修改、移动、旋转、删除及节点操作都进入撤销历史，一次拖动算一次操作。位置、尺寸等数字在按回车或离开输入框后应用并校验，方便键入小数。切换关卡、另存为独立关卡会重置当前关卡撤销历史。
- 正式接入自定义关卡的开发入口是 DemoEntry 的 Level Asset。编辑器试玩已经自动接入，无需使用者编写脚本。
- 工程内保存位置使用相对路径；Unity 资产中的关卡通过 GUID 跟随移动或改名。搬迁整个工程时保留 `.meta` 文件；搬迁关卡模块时保留内部 `Editor`、`Data` 结构。项目外保存的文件使用所选绝对路径，搬动这些外部文件后请重新打开。Unity 安装位置可自动发现，也可用验证脚本的 `-UnityPath` 指定。
