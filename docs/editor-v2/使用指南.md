# 新版街区关卡编辑器使用指南

本指南介绍新版街区关卡编辑器。它使用中文图形界面编辑十字路口地图、对象和移动路线；日常制作不需要编写 C# 或手工修改 JSON。编辑器仍依赖 Unity，不能脱离 Unity 单独运行。

新版编辑器面向街区关卡数据。旧 M0《第一步》编辑器处理另一种关卡格式；它的素材、盲道和对白步骤不适用于新版街区地图。旧版说明仍放在 [旧版编辑器指南](../LEVEL_EDITOR_GUIDE.md)。

## 打开编辑器

1. 用 Unity Hub 打开本工程，使用工程要求的 Unity 版本 **2022.3.62f1c1**，等待项目导入和资源解析完成。
2. 在工程根目录双击 **打开新版关卡编辑器.cmd**，启动 Unity 并打开新版工作台。工程已经打开时，启动器会提示从 Unity 菜单进入。也可以在 Unity 顶部菜单选择 **TingLu → 新版关卡编辑器**。
3. **TingLu → 关卡编辑器** 也会打开新版工作台。需要编辑旧 M0《第一步》数据时，使用 **TingLu → 旧版工具 → 第一步关卡编辑器**。

打开工作台后，先使用“开始向导”选一个起点。首次制作建议从“新建十字路口模板”开始；选择“空白关卡”则需要自行搭建地图。

## 工作台怎么分工

工作台按任务分为四个区域：

- **开始向导**：新建十字路口模板或空白关卡，并开始制作。
- **地图画布**：查看和编辑关卡的空间布局。这里编辑的是关卡真值地图；玩家运行时仍按正式游戏的探测、记忆和感知规则看到环境。
- **对象与路线**：选择地图对象，编辑对象属性、移动路线和相关设置。
- **检查与试玩**：查看检查结果、运行当前关卡预览，并导出关卡文件或可玩场景。

顶部常用操作包括“打开”“保存”“另存为”“撤销”“重做”“检查关卡”“试玩”和“导出JSON”。界面布局或按钮文字随编辑器迭代调整时，以当前工作台显示为准。

## 第一次制作：修改十字路口模板

1. 在“开始向导”选择 **新建十字路口模板**。模板带有可运行的道路、路口设施、交通和基本路线，适合先做小改动。
2. 使用“地图画布”浏览地图，选择需要编辑的地面或对象。要修改对象的具体属性、材质、分类或声音时，打开“对象与路线”中的对应项目。
3. 先做一个小改动，例如移动一件临时障碍、调整一段人行道边界，或微调一条行人路线。保留其他模板内容，便于先看清每项改动的效果。
4. 点 **另存为**，给关卡起一个新名字并选择保存位置。这样保留原模板，并为本次制作建立单独文件。
5. 点 **检查关卡**。阅读错误和警告，按提示选择相应对象修复。修复后再次检查，直到没有阻止试玩的错误。
6. 点 **试玩**，检查地图、移动路线、信号与声音在游戏中的表现。关闭或停止试玩后回到编辑器，按结果继续修改。
7. 再次保存，并根据交付需要选择 **导出JSON** 或 **导出可玩场景**。

## 空白地图的搭建顺序

空白关卡适合从头设计。建议先搭路面和可通行空间，再放置边界和对象，最后配置路线及游戏流程。

1. 在“开始向导”创建空白关卡，并填写关卡名称和目标提示。
2. 在“地图画布”绘制路面区域，区分机动车道、人行道、斑马线、坡道、路沿、盲道表面和小巷地面。关卡表面由区域轮廓和材质定义；坡道还需保持与两端地面平顺衔接。
3. 添加建筑边界和其他固定环境，检查玩家能够通过的开口与封闭边界是否正确。
4. 添加临时障碍和活动对象。为需要移动的车辆、行人或骑行者配置路线；为车辆路线核对行进方向、停靠位置及其信号关联。
5. 设置安全出生位置、检查点和终点。填写玩家能听到的目标提示，并确认预期路线可以到达终点。
6. 完成路线与属性后先检查，再试玩。沿预期路线实际走一遍，特别留意坡道连接、障碍间距、过街路线、动态对象与提示音是否协调。

## 地图元素和属性

新版地图包含地面表面、对象、移动路线、出生点、检查点、终点和目标提示。表面通常使用区域轮廓，并指定材质；对象则由位置、形状、材质和行为属性共同定义。

对象的类别表达它在环境中的状态：

- **永久环境**：建筑、路沿等稳定存在的环境。
- **临时障碍**：纸箱、施工围挡或停放车辆等可能改变位置或被移走的对象。
- **活动对象**：行驶车辆、骑行者、行人或动物等会移动或发出声音的对象。

碰撞、车辆危险、阻挡探测和声音遮挡是不同设置。按设计需要分别配置它们；对象发出声音不自动表示它是障碍，阻挡玩家移动也不自动表示它会完全遮住声音。活动对象的路线绑定对象，并由路线节点、速度和起始偏移距离描述其移动；可关联南北或东西信号及停止线距离。

表面材质影响游戏对道路区域的呈现与反馈。编辑时对照区域用途选择材质；不要用一整块大区域覆盖不同用途的道路，否则玩家难以通过纹理和脚步反馈区分环境。

## 保存、导出和试玩

- **保存**会将当前关卡写入所选文件。**另存为**用于建立独立副本或选择新的保存位置。关卡内容由界面序列化，不需要在文本编辑器里打开 JSON。
- **导出JSON**生成关卡数据文件，便于备份、交接或纳入其他流程。它是数据文件，不是可直接双击运行的游戏。
- **导出可玩场景**会生成 Unity 场景和同目录的关卡 JSON。导出前先保存或关闭当前未命名的 Unity 场景；选择 Assets 内的新场景文件名。导出后在 Project 面板双击该场景，再按 Unity 的播放按钮。保留同目录 JSON 和本工程资源。场景不会自动加入游戏构建列表。
- **试玩**用于检查当前关卡的实际游戏表现。通过编辑器检查只说明配置满足自动规则；是否容易辨认、声音是否合适、路线是否好走，仍要在试玩中确认。
- 关闭窗口、切换关卡或退出试玩前，先保存要保留的内容。若出现未保存修改提示，选择保存、放弃或取消，并确认自己想要的结果。

## 常见问题

**我看到了“第一步”模板或旧版关卡对象，怎么办？**

确认打开的是 **新版关卡编辑器**，然后从“开始向导”选择新建十字路口模板或空白关卡。旧版编辑器的第一步 JSON 与新版街区地图是不同格式。

**为什么检查通过后还要试玩？**

检查器可以发现缺失配置、无效引用和部分路线问题，但不能完整判断地图是否易于通行、声音提示是否清楚或玩家能否仅凭游戏反馈顺利完成路线。

**导出的 JSON 能直接运行吗？**

不能。JSON 保存的是关卡数据。要生成 Unity 可玩场景，请使用“导出可玩场景”。

**编辑器能脱离 Unity 使用吗？**

不能。它提供图形化制作界面，不要求用户写代码，但仍需要此工程和兼容版本的 Unity。

## 当前边界

新版编辑器按界面提供的地图、对象、材质、路线和检查项制作关卡。不要把旧版编辑器支持的素材或动作推断为新版功能；没有出现在新版界面中的能力，不应通过手改 JSON 添加。正式配音、声音导入、任意脚本逻辑等能力，只有在新版界面明确提供时才能使用。

## 随附示例与制作限制

可在工作台打开 Assets/TingLu/Levels/Data/StreetCrossroads.v2.json，或在 Unity 打开 Assets/TingLu/Scenes/Levels/StreetEditorExample.unity 试玩示例。保存自己的改动时建议另存为。

地面和实体轮廓需使用凸多边形，凹形区域可拆成几块。移动对象的路线第一个节点应与对象位置一致。自动检查通过不代表整张地图已证明可达；请实际走通出生点、检查点和终点。
