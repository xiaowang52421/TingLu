## 本角色任务

角色：相对鼠标与移动输入。独占 Assets/TingLu/Input；测试 Assets/TingLu/Tests/Upgrade/Role01；交接 UPGRADE_01.md。入口 Bootstrap 属于 00，不修改 DemoEntry。你必须在Input内实现可实际运行的Unity输入采样与指针生命周期组件（如InputSystemSampler/PointerCapture，命名自定），不是只给00提供修改建议；00只负责把组件接入入口。

在 G0 输入/坐标接口就绪后实现：
- 使用 Input System 的鼠标相对 delta，不读绝对屏幕位置。默认水平 delta 控制平面 yaw；垂直 delta 不转镜头。相对位移不要再乘帧 deltaTime 造成帧率相关速度；灵敏度和反向由共享配置注入。
- WASD/保留的方向键只输出归一化位移；不推算朝向。直接使用00在G0冻结的固定镜头地面基向量，使W/A/S/D对应画面方向；不等待07最终组件，07只验证同一映射。
- 右键 pressed edge 输出一次探测动作；长按不重复；空格不敲杖，Shift 不触发主动聆听。菜单用键与游戏动作隔离，右键/回车确认菜单不穿透到玩法。
- 实现可由 00/11 调用的指针锁定/释放与输入激活接口。游戏锁定并隐藏；菜单、暂停、失焦、退出释放；恢复时清掉累计 delta、按键沿和卡住移动。
- 保留原手柄/触屏兼容代码的必要接口，不扩展适配功能；本轮测试关卡不得因 Touchscreen.current 存在出现屏幕按钮。
- 不定义新公共 InputFrame，自 G0 正式类型消费；旧接口兼容由 00 明确策略。

验证 A03/A04/A05/A25/A28：静止转向、移动保持独立朝向、连续右键与长按、菜单返回、Alt+Tab、不同帧率/分辨率。提交组件挂接、生命周期与四方向输入示例。
