# 街区升级验收清单

本清单用于未来实现验收，不表示已经运行。文档审核只能验证需求与计划完整性。
每项未来记录 PASS / FAIL / NOT_RUN，附版本、入口、步骤及证据路径。自动测试、Unity 编译构建、实际画面/音频体验分别记录。

A01–A31为项目/游戏验收，A32–A34单列为下方流程合规表，编号保留便于需求追踪，不计游戏通过数。业务角色仅报告自己fixture/单元验证的子范围；整项PASS只由12在集成版本证据齐备时确认，00负责整体集成/修复。纯视觉、真实声音、设备与玩家体验不能用局部fixture代替。

A25由12在同一会话同时核对输入、菜单、角色计时、车辆/信号、探测/观测有效期、音频与恢复；01/02/03/04/06/10/11分别交局部证据。A30由12执行整条通关链，09/10/06分别提供地图、存档恢复、声音证据。多人参与不等于多方各自认证；结论不同时保留原始证据，由12在同一构建/配置复现，未解决失败不能标整项PASS。

## 建议自动验证

优先对会出错的行为做有意义测试：移动/朝向解耦、输入边沿、扇形裁剪、覆盖并集与局部减法、快照不可变、同 ID 迁移、声音不揭图、恢复事务与存档隔离。
不为纯文本、简单常量或低影响样式镜像实现堆砌测试。按实际变更选择既有工具；新验收脚本在 tools/upgrade，禁止假定尚不存在的脚本已经可运行。

## 必须人工或实机验证

2.5D 画面、不同纹理可辨性、鼠标转向手感、临时旧记录是否容易理解、真实声音方向与距离、交通信号音和碰撞恢复、黑暗中不探测移动的体验。Windows 构建成功并不代表这些通过；未执行项标 NOT_RUN。
