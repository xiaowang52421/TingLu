# 对象移动、碰撞恢复与深红边缘反馈

本次修复只在 `D:\听路_街区升级` 进行。完成本地验证后，按用户追加指令发布 [2026-10-20 Windows 预发布版](https://github.com/xiaowang52421/TingLu/releases/tag/street-2026.10.20-preview.1)。原 `D:\听路`、旧存档和既有试玩包保持只读；用户新增关卡和预览场景保留。验证使用 `output/collision-upgrade-20261020/validation-project` 独立工程，不关闭用户正在打开的 Unity 预览。

## 根因与修改范围

1. 旧 `StreetWorld.VehicleContacts` 将没有路线的危险标记对象也报告为车辆事故；`Move` 同时跳过危险标记对象，停车车可能没有普通阻挡。
2. 普通碰撞原先会扣勇气、眩晕，勇气耗尽还会间接回档。本次普通接触只发反馈事件，不应用旧伤害/眩晕值，不进入失败路径。
3. 编辑器原先只有汽车、电动车、行人泛型模板，行人和车辆的实体与动静配置不完整。
4. 新增统一玩家实体接触来源，玩家控制器合并两个接触来源后优先处理危险车辆；会话在 `Player.Contacted` 发起独立的光晕，恢复检查点不清理它。
5. 保留按路线分段的相对运动扫掠和危险接触去重；逐个运动区间判断实际位移，并修正边界重叠与扫掠的数值容差不一致。静止、结束路线、红灯等待的区间不具有危险资格。

## 规则对照

| 对象及碰撞时状态 | 实体接触与阻挡 | 深红边缘光晕 | 恢复检查点 |
| --- | --- | --- | --- |
| 行走行人 | 有 | 是 | 否 |
| 静止行人 | 有 | 是 | 否 |
| 行驶汽车 | 有 | 是 | 是 |
| 停放汽车 | 有 | 是 | 否 |
| 行驶自行车、电动车 | 有 | 是 | 是 |
| 停放自行车、电动车 | 有 | 是 | 否 |
| 建筑、墙、路障等普通实体 | 有 | 是 | 否 |
| 因红灯或路线结束已经停车的车辆 | 有 | 是 | 否 |

危险碰撞同步恢复最近**已经激活**的检查点；尚无检查点时恢复关卡的安全出生位置。不会等待光晕播完。恢复会重置交通和玩家时间线，光晕采用独立的播放时间，保留本次脉冲。恢复/读档时已经重叠或贴住的对象需要先分离，才形成新的接触。一个模拟步的多危险触点仅恢复一次。

普通碰撞保留碰撞声音，不扣勇气、不产生碰撞眩晕、不进入失败或回档。旧文件中的 `contactDamage/contactStun` 仍可往返保存，但不再应用于普通碰撞。

## 编辑器操作

1. 从 `TingLu → 关卡编辑器` 或根目录 `打开新版关卡编辑器.cmd` 打开新版街区编辑器。
2. 地图画布的“对象”栏可直接选择“行走行人/静止行人”“行驶汽车/停放汽车”“行驶自行车/停放自行车”“行驶电动车/停放电动车”。
3. 移动对象自动建立初始路线；在右侧“移动状态”选择静止或沿路线移动，并编辑速度（米/秒）、循环、节点、停车线与信号控制。静止对象无需填写路线。
4. 使用草稿保存、重新打开、“检查与试玩”、JSON 导出或“导出可玩场景”。导出场景绑定相邻 JSON，预览与自制关卡继续使用隔离存档空间。

路线是移动**配置**；危险资格依据碰撞时运动分段的真实位移。类别、危险旧标记、路线存在、声音与记忆类型均不能单独证明实际运动。编辑器列表的“行驶”表示已配置移动路线，车辆运行时仍可能临时停车。

## 光晕参数和生命周期

集中配置在 `StreetEntry` 的 `configuration → CollisionFeedback`，代码默认值位于 `Assets/TingLu/Config/Shared/StreetConfig.cs` 的 `StreetCollisionFeedbackConfig`：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| Red / Green / Blue | 0.36 / 0.012 / 0.028 | 深红颜色 |
| Intensity | 0.8 | 最大强度 |
| EdgeWidth | 0.14 | 相对窗口短边的边缘宽度 |
| Duration | 0.72 秒 | 单次闪烁及淡出总时长 |
| RepeatInterval | 0.22 秒 | 新脉冲的最短触发间隔 |

光晕只使用屏幕坐标，不读取或显示隐藏对象的位置、轮廓和世界模型。四周透明度柔和向内降为零，中央不绘制红色。它不修改移动、交通、存档、数值、感知与探索记忆。

持续顶住同一对象不重复产生玩家接触事件；分离并再次接触可以重新触发。活跃脉冲内的碰撞合并，不叠加强度，不延长本次脉冲；超过播放时长及最短间隔后可开始新脉冲。暂停既冻结事件生成也冻结播放时间。新开游戏、读档、返回主菜单或销毁会话清理残留；危险检查点恢复保留本次光晕。

## 兼容性

保持关卡 schema 2，新增可选 `actorKind`。旧 JSON 缺少该字段时按既有人物语义、声音及旧车辆标记兼容识别类别，随后仍按真实运动分段判断事故。无路线但带旧车辆危险标记的对象是静止实体。行人即使遗留车辆标记，也不继承车辆事故规则。

旧的空轮廓纯声源保持声源用途，不凭类别凭空生成碰撞形状。带实体轮廓的静止行人停止行走声，停车车辆不默认播放行驶声；鸟鸣、信号灯和纯声源维持原有规则。未知区、敲杖、遮挡和临时对象记忆沿用既有链路。

## 人工边界

开发 Player 的确定性输入和后缓冲截图可证明软件行为，不等于真人键鼠、物理设备听辨或真人无障碍验收。本机 Player 仍报告中文语音合成不可用警告，日志完整保留；本次没有修改语音后端，不能据自动化通过声称真实语音已验收。任意用户自制关卡的整体可达性也不由本次测试自动保证。

实际窗口覆盖 1280×720、960×640 和 720×960；其他宽高比有 6 种数学采样测试，但未逐一打开真实窗口。未手工拖动运行中窗口或核验多显示器/DPI 切换。没有真人逐项点击全部编辑器按钮的签收；自动化覆盖的是相同编辑、文件和运行接口。新建的通用传送功能不在本次范围，既有读档和检查点恢复链路已经覆盖。

同一步刚进入检查点且同时受撞时，恢复此前已经激活的检查点；没有为播放反馈延迟事故处理。
