# 街区升级需求与规则

日期：2026-10-15。状态：文档评审版，未开始升级开发。
工程：D:\听路_街区升级。原项目 D:\听路 只读保护。

## 已确认需求

| 编号 | 用户确认内容 | 约束 |
| --- | --- | --- |
| R01 | 在独立副本升级 | 所有写入、构建和新增文档都在副本；原项目保持现状 |
| R02 | 2.5D，类似 JRPG | 固定斜俯视镜头，跟随人物平移；鼠标转向不旋转镜头 |
| R03 | 键盘只负责移动，鼠标负责转向 | 鼠标相对位移控制平面朝向，隐藏并锁定指针；禁止指针指向式瞄准 |
| R04 | 右键触发盲杖 | 按下一次触发一次；不要求持续按住或拖拽；空格不再触发盲杖 |
| R05 | 聆听改为被动技能 | 删除 Shift/按住聆听要求；保留原有专注、冷却、消耗与混淆机制，数值后调 |
| R06 | 取消所有屏幕操作按键 | 游戏中无方向、聆听、敲杖、暂停、目标等虚拟操作按钮；连接触屏也不自动恢复 |
| R07 | 黑暗背景、简化纹理 | 未探索环境纯黑；已探明地面用颜色与纹理区别盲道、人行道和机动车道 |
| R08 | 战争迷雾式探索 | 扇形实际探测覆盖连续累积，无玩法网格；不探测也可以移动并发生真实碰撞 |
| R09 | 扇形盲杖 | 以敲杖瞬间人物位置和朝向为基准；不再使用旧版 360°敲杖 |
| R10 | 永久环境持续保留 | 本次实际覆盖内的永久环境全部被确认；离开后作为较暗的已探索记忆保留 |
| R11 | 建筑不可穿过，探明后显示 | 需要兼容店铺入口和小巷；测试关卡有建筑边界和小巷，不放店铺内容 |
| R12 | 永久环境与临时障碍区分 | 固定建筑、路沿等为永久；停放自行车、纸箱、施工围挡等为临时 |
| R13 | 临时障碍保留上次探测位置 | 离开当前探测后用变暗、虚线/纹理表达旧记录；再次实际覆盖时才刷新或删除 |
| R14 | 活动对象独立分类 | 骑行者、行人、车辆、动物等可听对象由被动听觉定位，无须盲杖；不存成永久障碍 |
| R15 | 测试地图是普通二线城市老城区十字路口 | 要有可实际通过的斑马线、红绿灯及提示音、路沿和坡道、盲道转弯及提示砖、盲道被占用、施工围挡、停放车辆、行人和行驶车辆 |
| R16 | 测试地图不放公交站、店铺、树池、电线杆、井盖 | 扩展结构可以预留，不制作这些内容，也不强制安排专项开发 |
| R17 | 可以真实过马路 | 进入车道不额外提示、不扣值、不判失败；红灯期间同样不人为拦住玩家 |
| R18 | 被车撞后回检查点 | 实际车辆碰撞触发恢复；不等勇气归零；无检查点时回安全起点 |
| R19 | 不显示脚下文字 | 不提供“当前脚下：盲道/人行道/机动车道”HUD；靠已知纹理和材质脚步表达 |
| R20 | 暂不升级关卡编辑器 | 保留现有工具；允许为新测试关卡增补运行时数据能力，不扩展编辑器工作台 |
| R21 | 一个主控，多执行角色，可并行 | 主控 gpt-6.1-sol/high；执行及验收 gpt-6-luna/xhigh；按可用并发槽分批 |
| R22 | 先编写并检查文档 | 当前交付只有文档；得到开始开发指令后再派发实现 |
| R23 | 主控有权部署、撤销、拆分和重分配子 Agent | 开发启动后按进度/负载自主调度；每次写清子任务提示词并向用户汇报，需要时提问确认；不突破实际并发槽和既定范围 |

## 迷雾的四种信息

| 信息 | 当前有效探测/感知 | 离开后 | 再次探测/感知 |
| --- | --- | --- | --- |
| 未探索环境 | 只有实际合法探测覆盖才显现 | 仍未覆盖处继续纯黑 | 新覆盖与历史覆盖连续合并 |
| 永久环境与地面 | 本次实际覆盖内清晰显示 | 较暗、稳定保留已确认部分 | 更新实际确认部分，不能扩散到整栋建筑 |
| 临时障碍 | 显示本次真实探测到的局部轮廓 | 变暗、虚线或纹理，冻结在上次位置 | 仅对实际覆盖部分确认仍在、已移动或已空置 |
| 活动声源 | 依据可听范围、遮挡及可辨度显示短时声纹/定位 | 超出有效感知后按原短时规则消失 | 新听觉结果刷新，不读真值跟踪 |

这些是信息状态，不是地图格子。实现可用连续多边形、裁剪片段或内部纹理遮罩；禁止把内部采样分辨率变成玩家必须逐格解锁的玩法。

例：在 A 点朝东敲杖，探明一段人行道、其中的盲道、建筑边界和一辆停放自行车。朝北移动后，这些已知永久环境变暗但保留，自行车留下旧位置虚线。自行车被移走时，旧记录不自动消失。只有下一次探测实际覆盖原位置、且未被遮挡，才清理对应旧记录。与此同时，未探索道路上的行驶车辆可先被听见，但其声音不揭开地面或整车轮廓。

## 默认实施方案：已明确标注，可后续调整

以下为补足实现细节的建议，并非用户逐项指定的最终策划数值。主控在开发前记录到升级决策表；不为这些常规选择重复请求许可。

| 编号 | 默认方案 | 原因及限制 |
| --- | --- | --- |
| D01 | WASD 按固定镜头投影的画面方向移动，斜向归一化；移动不改变朝向 | 用户选择相对鼠标转向，未进一步指定移动参照系；此方案便于固定镜头操作 |
| D02 | 鼠标水平相对位移改变地面平面的朝向；垂直位移暂不使用 | 不改变镜头俯角，不引入跳跃或上下看；保留灵敏度与反向设置 |
| D03 | 被动听觉一直工作；移动时原速度与专注消耗保持，静止时使用原聆听恢复率 | 避免把始终聆听错误实现成始终低速、始终恢复专注；原低专注/混淆仍生效 |
| D04 | 有效听觉可来自四周，方向主要影响声像和前向清晰度 | 车辆可以从后方被听见；不把盲杖扇形当作声音硬裁剪范围；具体衰减待调 |
| D05 | 扇形被建筑等硬屏障裁剪，确认其中可达覆盖内的所有永久环境 | “全部”指实际探明范围；不穿墙揭开背面，不跨整物体自动解锁 |
| D06 | 不透明临时障碍可影响本次遮挡，是否遮挡由材质/定义配置 | 不能一律把纸箱、自行车都当成无限高不透声墙；声音与几何探测分开计算 |
| D07 | 已探索永久环境随存档保存；临时旧记录可保存，读档后仍为待复核状态 | 读档不把旧快照冒充当前真值；恢复后重新计算活动声源 |
| D08 | 车辆碰撞包含机动车、电动车及正在骑行的自行车 | 任一真实车辆碰撞均回检查点；行人、动物不因此自动触发车辆失败 |
| D09 | 普通非车辆碰撞沿用原工程规则 | 保留现有勇气和接触去重；本轮不擅自改成所有碰撞都重来 |
| D10 | 暂停/设置菜单保留正常菜单项，使用 Esc 进入；屏幕不放额外操作面板 | “取消屏幕按键”落实为取消游戏虚拟按键与触屏覆盖层；不删开始、退出、设置菜单 |
| D11 | 测试关卡以新入口/新数据进入；副本旧《第一步》保留作为回归样例 | 不重写原关卡，不要求旧关卡采用新地图结构；主控隔离模式和存档 |
| D12 | 普通路沿表现高度与材质边界，坡道提供顺畅连接 | 不默认让所有低路沿成为不可跨越墙；建筑与封闭围挡仍有真实阻挡 |
| D13 | 声源分类与物理碰撞独立 | “不算障碍”指不归入静态/临时探测记忆；车辆仍可撞击，行人不自动变成不可穿过屏障 |
| D14 | 2.5D 优先保留现有纯 C# 平面模拟，展示层映射到固定斜俯视空间 | 不为了视觉风格无必要地替换全部物理系统；具体映射由主控冻结 |
| D15 | 新测试关卡的永久探索不因车辆碰撞回检查点而回退；临时记录恢复为过时，活动感知重算 | 让“永久显示”的空间记忆持续保留；世界/角色按检查点恢复，尝试统计不回滚；旧首关可保留旧恢复策略 |

## 数值处理

保留现有 GameplayConfig 作为可运行的临时基线，不把字段置空、NaN 或负数来表达“以后再填”。沿用数值不代表它们已经通过本次街区体验验证。

| 项目 | 文档阶段处理 |
| --- | --- |
| 原速度、专注上下限、移动消耗、静止恢复率 | 沿用现有有效值；被动化改变触发条件，具体强度后调 |
| 敲杖成本、冷却、混淆窗口及持续时间 | 沿用现有有效值，统一配置；无效右键不扣资源 |
| 扇形角度 | 新增明确配置项，禁止默认为 360°；主控填一个有效且小于 360°的联调临时值并标注待调 |
| 扇形半径与当前显影时间 | 半径可沿用旧有效值，当前亮度沿用短时显影；历史覆盖不随显影消失 |
| 鼠标灵敏度、镜头倾角/缩放、纹理亮度 | 可运行临时配置，集中记录，留给试玩调整 |
| 交通信号周期、车辆速度及密度 | 协调配置并验证路线；本轮无最终平衡承诺 |

## 测试关卡范围

一处十字路口，四段道路连接，两侧人行道与连续/转弯盲道，至少一处盲道被占用与可绕行空间。四向车道和斑马线布局自洽，信号相位驱动车流与过街提示音。建筑挡住越界通路，小巷至少包含一处可进入支路，店铺入口数据能力预留但不摆店铺。

至少有安全出生点、过街前检查点、过街后安全落脚处和可识别终点；具体数量与坐标由关卡角色提出，主控验证。车辆路线、行人和动物声源都需要能在玩家运行中真实工作。可将鸟鸣作为动物活动声源，不强制复杂动物 AI。

玩家可主动走到未知区域、可不等绿灯过街；只有实际车辆碰撞触发车辆恢复。交通提示音属于环境声，不等同于“你进车道了”的自动警告。暂停必须冻结车辆、信号相位、探测计时及危险判定。

## 本轮不包含

现有关卡编辑器工作台升级、完整城市生成、公交系统、店铺内容、联网、移动端触控适配、新增付费音频 SDK、大规模素材制作、全部章节重制。测试地图外的城市设施只作为扩展方向，不列为本轮验收缺口。
